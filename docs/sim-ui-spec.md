# スマホ蛍シミュレーション UI — 仕様書

> **ステータス:** 仕様更新版（§12 回答・追加要望を本文に反映）  
> **対象:** Web 実験から書き出した JSON を読み込み、実験確認・位相振動子シミュレーションを GUI で行う  
> **関連:** [README.md](../README.md) / [sim/](../sim/) / [`shared/session-export.schema.json`](../shared/session-export.schema.json)  
> **UI 技術（確定）:** NiceGUI（ローカルブラウザ）

---

## 1. 目的

授業中にターミナル操作を最小限にし、次を GUI で行う。

1. Web から取り出した実験 JSON を UI から読み込む  
2. **実験結果確認モード**で実験1・実験2の周波数などを、時間窓を指定して解析する  
3. その窓から得た \(\omega_i\) と結合強度 `a` 等を使い、**時間発展** / **分析**シミュレーションを行う  
4. 必要に応じて、結合なし・2振動子などでシミュレーションの正しさを段階検証する  

---

## 2. 用語

| 用語 | 意味 |
|------|------|
| 振動子 | 各席（机）に対応する位相変数 \(\phi_i\) |
| 位相ゼロ | \(\phi \approx 0 \pmod{2\pi}\)。タップ（発光）に対応 |
| 自然角周波数 \(\omega_i\) | **実験結果確認モードで指定した時間窓**内のタップから算出。\(\omega_i = 2\pi f_i\) |
| 結合強度 \(a\) | \(a_{ij} = a / r_{ij}\) のスカラー。音量に相当 |
| セッション JSON | Web の「JSON ダウンロード」で得たファイル |
| 基準振動子（ID1） | 位相差表示の基準。机一覧の先頭（読込順の 1 番目）を ID1 とする |
| ポアンカレ断面 | ID1 が位相ゼロを通過した瞬間。その時刻での他振動子との位相差を記録・描画する |

---

## 3. 全体構成

```text
[セッション JSON]
       │ 読込
       ▼
[共通: ファイル情報 / a / dt / 積分法 / 初期位相ランダム化]
       │
       ├─ 実験結果確認モード  → 窓指定で f, ω を確定（シミュレーション入力）
       ├─ 時間発展モード      → 1施行のリアルタイム可視化
       ├─ 分析モード          → 過渡後の実効周波数分布
       └─ 検証モード（段階確認）→ 結合なし / 2振動子など
```

- 起動: **1コマンド**または簡易ランチャ（`.bat` / 将来的な exe 相当）  
  例: `python -m sim.ui` または `run_sim_ui.bat`  
- UI: NiceGUI がローカルブラウザを開く  

---

## 4. 共通機能

### 4.1 データ読込

| 項目 | 仕様 |
|------|------|
| 入力 | ファイル選択でセッション JSON を指定 |
| 形式 | Web エクスポートと同一（`desks`, `experiment1`, `experiment2`, …） |
| 必須 | `desks` と、実験1・2いずれかのタップ列 |
| 失敗時 | 読めない・タップ不足の机は**警告表示**し、使える振動子だけで続行 |

**派生量**

- 机 ID → \((x, y)\)［m］  
- **\(\omega_i\) は実験結果確認モードの窓から確定**したものをシミュレーションで使用（窓未設定時は実験1全区間などフォールバック方針を UI 上で明示）  
- 距離行列 \(r_{ij}\)、結合 \(a_{ij} = a / r_{ij}\)（対角は結合なし）  

**読込後の表示**

- `sessionId`、振動子数  
- 机 ID・座標・（窓確定後の）\(f_i, \omega_i\)  

### 4.2 共通パラメータ（UI）

| パラメータ | 意味 | 既定 | 操作 |
|------------|------|------|------|
| \(a\) | 結合強度 | `1.0`（範囲の目安 0〜2、上限は UI で変更可でも可） | スライダー + 数値 |
| \(\Delta t\) | 積分刻み | `0.01` s | 数値（折りたたみ可） |
| 積分法 | RK4 / Euler | RK4 | セレクト |
| 乱数シード | 再現用 | 未指定なら都度ランダム | 任意 |

**実行中の `a` 変更（確定）:** 時間発展の実行中も **即反映**する。

### 4.3 初期位相

- \(\phi_i(0) \in [0, 2\pi)\)  
- **「初期位相をランダム化」**で一括再抽選  
- **モードごとに独立**に保持する（時間発展用 / 分析用で別）  

### 4.4 同一机の複数人表示

- 結合エッジ線は**出さない**（距離は 2D 配置で読み取る）  
- 同じ机に複数いる場合は、ノードが重ならないよう **少しずらして配置**する（Web 側の `A2-1` 等の座標を尊重し、それでも近い場合は表示用オフセットを追加）

## 5. モード 0 — 実験結果確認

### 5.1 目的

実験1・実験2の実測タップを確認し、**周波数分布の解析に使う時間窓**を指定する。  
収束途中だけを誤って使わないようにする。  
**この窓内のデータから各振動子の \(f_i\)（→ \(\omega_i\)）を決め、以降のシミュレーション入力とする。**

### 5.2 操作

| 操作 | 内容 |
|------|------|
| 実験切替 | 実験1 / 実験2 |
| 時間窓 | 開始時刻・終了時刻（実験開始からの ms または s）。スライダーまたは数値 |
| 再計算 | 窓変更のたびに周波数・ヒストグラムを更新 |
| シミュレーションへ適用 | 現在の窓（主に実験1）から得た \(\omega_i\) を「採用」して時間発展・分析で使う |

### 5.3 表示

| 表示 | 内容 |
|------|------|
| 各机のタップ時刻列（簡易） | 窓の内外が分かる程度 |
| 周波数一覧 | 窓内タップから求めた \(f_i\) |
| 周波数ヒストグラム | 実験1・実験2それぞれ |
| 実験2との比較 | 実験2がある場合、分布を並べる / 重ねる（**必須**） |

### 5.4 \(\omega\) 決定ルール（確定）

1. ユーザーが実験結果確認モードで窓を指定する  
2. 各机について、窓内のタップ間隔から平均周期 → \(f_i\) → \(\omega_i = 2\pi f_i\)  
3. 窓内タップが不足（2回未満など）の机は除外または警告  
4. 「採用」した \(\omega\) セットを時間発展・分析・検証が参照する  

> 既定の初期窓案: 実験時間の後半 50%（収束待ち）。UI で変更可能。

## 6. モード A — 時間発展シミュレーション

### 6.1 目的

1 施行の時間発展を、空間配置とグラフでリアルタイム観察する。

### 6.2 操作

| 操作 | 内容 |
|------|------|
| 初期位相ランダム化 | \(\phi_i(0)\) を再設定し表示リセット |
| 開始 / 一時停止 / 停止 | 再生制御 |
| シミュレーション速度 | 実時間に対する倍率（例: 0.25×〜10×） |
| `a` | **実行中も即反映** |

### 6.3 空間表示（ノード図）

- Web 座標に基づく 2D ノード、ラベルは机 ID  
- 結合線なし。同一机はずらして表示  
- **発光（確定）:** 位相がゼロを通過した瞬間から、**実時間で約 0.1 秒**点灯。色は**緑系（蛍）**  
- ゼロ通過の検出は可視化用（方程式には非介入）  

### 6.4 リアルタイムグラフ（確定）

| グラフ | 内容 |
|--------|------|
| 波形の時間発展 | 縦軸は **\(\sin\phi_i(t)\)**（位相そのものではない）。同期が見やすいこと優先。全本 / 選択のみ切替 |
| 表示時間幅 | **UI で設定可能**（スライディング窓 \(T_{\mathrm{window}}\)） |
| 位相差（ポアンカレ） | **ID1（先頭振動子）が位相ゼロを通過した時点**を断面とし、その瞬間の \(\phi_j - \phi_1\) を \([0, 2\pi)\) に畳んでプロット。横軸は断面の通し番号またはその時刻 |
| 秩序パラメータ | \(R(t) = \lvert\langle e^{i\phi}\rangle\rvert\) をリアルタイム表示 |

### 6.5 数値・モデル

\[
\dot\phi_i = \omega_i + \sum_j \frac{a}{r_{ij}}\sin(\phi_j - \phi_i)
\]

- 積分: 既定 RK4（`sim/model.py` と共通）  
- \(\omega_i\) はモード 0 で採用した値

## 7. モード B — 分析モード

### 7.1 目的

ランダム初期位相から積分し、過渡の後に計測区間の実効周波数分布を得る（資料のヒストグラム比較用）。

### 7.2 操作・パラメータ

| パラメータ / 操作 | 内容 | 既定案 |
|-------------------|------|--------|
| 初期位相ランダム化 | ボタンのたびに再抽選 | — |
| 過渡時間 \(T_{\mathrm{transient}}\) | 周波数集計に使わない | `20` s（UI 変更可） |
| 計測時間 \(T_{\mathrm{measure}}\) | 過渡後にゼロ交差を集める長さ（**UI で指定**） | `10` s |
| \(a\) | 共通パラメータ | `0` / `0.3` / `1` などを試す |
| 実行 | 「分析を実行」（一括計算で可） | — |

### 7.3 処理手順

1. 採用済み \(\omega_i\)・座標・初期位相を用意  
2. \(0 \rightarrow T_{\mathrm{transient}}\) を積分（計測しない）  
3. 続けて \(T_{\mathrm{measure}}\) でゼロ交差を記録  
4. 実効周波数 \(f_i^{\mathrm{eff}}\) を算出  
5. 結果表示  

### 7.4 結果表示

| 表示 | 内容 |
|------|------|
| ヒストグラム | \(f_i^{\mathrm{eff}}\)。**実験1自然周波数**および **実験2実測**（窓適用後）と**重ね描き必須** |
| 一覧表 | 机 ID, \(f^{\mathrm{natural}}\), \(f^{\mathrm{eff}}\), （あれば）実験2実測 \(f\) |
| 指標 | 計測末付近の \(R\) など |

## 8. モード C — 検証モード（段階確認）

シミュレーション実装が理論どおりかを、授業・開発の両方で段階的に確認する。

### 8.1 ステップ（必須の流れ）

| 段階 | 内容 | 確認の目安 |
|------|------|------------|
| C1. 結合なし（\(a=0\)） | 各 \(\phi_i(t) = \phi_i(0) + \omega_i t\)（mod \(2\pi\)） | \(\sin\phi_i\) の周期が \(2\pi/\omega_i\) と一致。ノード発光間隔もそれに対応 |
| C2. 2振動子 + 結合 | 机を2つ（またはデータを2人に絞る）に限定し \(a>0\) | 位相差の振る舞いや実効周波数が、近接振動子の理論的期待（同期・ドリフト等）と qualitatively / 可能なら quantitatively 一致 |
| C3.（任意・後続） | N 振動子・格子配置 | 時間発展・分析モードの通常利用へ |

### 8.2 UI

- 検証段階を選ぶセレクト（C1 / C2）  
- C1: 現在の \(\omega\) で \(a=0\) 固定の短時間ラン＋理論曲線オーバーレイ  
- C2: 振動子を2つ選ぶ（既定: ID1 と ID2）、\(a\) と距離は実座標から計算  
- 合否は自動判定できなくてもよいが、**理論値または期待される定性を画面に短く表示**する

## 13. 受け入れ条件

### 実験結果確認

- [ ] 実験1・2を切り替え、時間窓を指定できる  
- [ ] 窓内データから周波数分布が出る  
- [ ] 実験2との重ね / 並べ比較ができる  
- [ ] 採用した窓がシミュレーションの \(\omega_i\) になる  

### 時間発展

- [ ] JSON 配置どおりノード表示（同一机はずらす）。結合線なし  
- [ ] 初期位相ランダム化できる  
- [ ] 位相ゼロ通過後、実時間約 0.5 s 緑発光  
- [ ] 速度変更・実行中 `a` 即反映  
- [ ] \(\sin\phi_i(t)\)（時間幅可変）、ID1 ポアンカレ位相差 \([0,2\pi)\)、\(R(t)\) が更新される  

### 分析

- [ ] 過渡・計測時間を UI 指定  
- [ ] 初期位相ランダム化  
- [ ] 実効周波数ヒストに自然周波数・実験2実測を重ねられる  

### 検証

- [ ] \(a=0\) で理論どおりの時間発展を確認する画面がある  
- [ ] 2振動子結合の確認ステップがある

## 16. 実装時のメモ（開発者向け）

- ポアンカレ断面は「ID1 のラップ（ゼロ交差）」イベントでサンプリング  
- 発光はシミュレーション時刻ではなく **壁時計で 0.5 s** のフェード／点灯フラグ  
- \(\omega\) 未採用のまま時間発展を開始した場合は、採用を促すダイアログか、明示的フォールバックを表示  
- 検証 C2 の「理論」は、資料・授業進度に合わせて文言を調整（厳密解が無い場合は定性ガイド）
